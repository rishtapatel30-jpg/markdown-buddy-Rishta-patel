# Assignment Reflection

## 1. What were the strengths and weaknesses of using AI-assisted documentation workflows?
- **Strengths:** AI quickly generated structured templates, professional headers, and boilerplate sections (like Installation and License) that saved significant time. It also helped maintain consistency across Markdown syntax.
- **Weaknesses:** AI-generated drafts sometimes lacked project-specific context, requiring manual intervention to accurately reflect the actual dataset inputs, paths, and script functions.

## 2. How did you ensure ethical use and validation of the Al outputs?
I followed the verification pattern by manually reviewing every line of AI-generated Markdown, checking syntax errors, previewing files on GitHub and RStudio, and ensuring that no real or confidential data was uploaded to the AI tool.

## 3. How did iterative prompting improve your final documentation?
Using a multi-step prompting approach (moving from a seed prompt to a refinement prompt, and finally a critique/validation prompt) allowed me to progressively tighten the tone, make sections concise, and fix minor formatting bugs before finalizing the files.
